Cost analysis and profitability assistant

Enter revenue and cost figures for the current year (and optionally the previous year). The app calculates margins, cost structure, break-even, operating leverage, per-unit figures and data checks in code, so the numbers are exact. Claude then writes the analysis using the rules in a written Skill (SKILL.md).
